# Kedai Senja Coffee (Demo Fiktif)

Website demo satu halaman untuk latihan dan portofolio AHYAR.
Kedai Senja Coffee adalah usaha fiktif. Semua alamat, harga, dan jam buka bukan data nyata.

Dibuat dengan HTML, CSS, dan JavaScript (tanpa framework).

Untuk melihatnya secara lokal, buka `index.html` di browser.
